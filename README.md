# Utilidades MX

Sitio web estático para México, con cuatro herramientas: calculadora de IVA, contador de palabras, generador de contraseñas y división de propina. Las páginas están en carpetas con index.html.

## Desplegar

Conectar este repositorio a Vercel o Cloudflare Pages, directorio raíz ./, sin comando de build. Dominio previsto para enlaces SEO: https://utilidades-mx-yamis-projects-c7b04fa6.vercel.app. Actualizar canonical/sitemap si el dominio cambia.

## Monetización

Sin anuncios ni cobros activados. No habilitar un acceso Pro con ?pro= o un código público en el cliente: requiere autenticación y verificación del pago mediante un webhook en backend.

## Privacidad

Las herramientas procesan entradas localmente. Revisar avisos legales y configurar contacto verificado antes de habilitar formularios, anuncios o pagos.
